# Streamer-Setup – Importieren, OBS, fertig

1. Öffne den bereitgestellten StreamElements Share-Link.
2. Übernimm das Overlay in deinen StreamElements-Account.
3. Füge den Overlay-Link als Browserquelle in OBS ein.
4. Fertig.

Das Widget erkennt deinen Twitch-Kanal automatisch. Du brauchst keine Twitch-App, kein OAuth, keinen Bot, keine ID, keinen Eventcode und keine Supabase-Daten.

Falls im StreamElements Editor „Dieser Kanal ist nicht freigeschaltet“ erscheint, melde dich bei der Eventorganisation. Der Share-Link registriert niemals automatisch neue Teilnehmer.

Vor dem Start kann das Overlay dezent verborgen bleiben oder „Event startet bald“ anzeigen. Aktivierung, Pause und Fortsetzung erfolgen später zentral – du musst den Link nicht erneut importieren.

Bei einem Minion erklärt die eingeblendete Infobox den einheitlichen Chatcommand `!boss`. Das Widget schreibt selbst keine Nachrichten in den Chat und benötigt keinen Bot.
