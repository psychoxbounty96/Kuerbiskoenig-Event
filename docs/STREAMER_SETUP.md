# Streamer-Setup

1. Öffne den von der Eventorganisation bereitgestellten StreamElements Share-Link.
2. Übernimm das Overlay in deinen StreamElements-Account.
3. Füge den Overlay-Link als Browserquelle in OBS ein.
4. Fertig.

Das Widget erkennt deinen Twitch-Kanal automatisch. Du benötigst keinen Bot, keine OAuth-Anmeldung und keine technischen Zugangsdaten.

Falls „Kanal nicht freigeschaltet“ erscheint, wende dich bitte an die Eventorganisation. Es wird niemals automatisch ein Teilnehmerkonto angelegt.
